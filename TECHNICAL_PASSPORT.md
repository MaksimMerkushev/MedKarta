# Технический паспорт проекта: Med-Navigator (MedKarta)

> **Документ устарел.** Паспорт описывает раннюю версию проекта (хостинг
> Vercel, Leaflet Routing Machine, каталоги `src/` и `api/`). Текущая
> архитектура, стек и возможности — в технической документации
> [`docs/README.md`](docs/README.md). Текст паспорта сохранён как исторический.

## 1. Общее описание

Med-Navigator — это интерактивная веб-платформа для поиска врачей и медицинских клиник в Казани с системой умной навигации. Приложение объединяет картографический сервис и AI-помощника для автоматизации поиска и построения маршрутов.

## 2. Технологический стек

- Frontend: React (Vite), Tailwind CSS.
- Картография: Leaflet, React-Leaflet.
- Навигация: Leaflet Routing Machine.
- Иконки: Lucide React.
- AI: обращение к провайдеру LLM через собственную serverless-функцию (Vercel Functions).
- Хостинг: Vercel (статика + функция api/chat.js).

## 3. Основной функционал

- Интерактивная карта: отображение сотен медицинских объектов с кластеризацией.
- Умные фильтры: поиск по специализации, району (Вахитовский, Советский и др.), типу собственности (гос/частные), доступности (открыто сейчас) и детским отделениям.
- Система маршрутов: возможность добавления нескольких точек посещения. Маршрут строится динамически с выбором способа передвижения (авто, пешком, велосипед).
- AI-ассистент: понимает естественный язык. Может найти врача по жалобе ("болит ухо"), отфильтровать клиники ("покажи только государственные") и построить маршрут ("проложи путь до РКБ") через JSON-команды.
- Личный кабинет: система «Избранного» (хранится в LocalStorage).

## 4. Ключевые архитектурные решения

- Маршрутизация через AI: системный промпт живёт на сервере (api/_shared/prompt.js) и заставляет модель возвращать строго структурированный JSON. Ответ нормализуется по белым спискам (api/_shared/sanitize.js) и только после этого применяется к состоянию UI.
- Ключ API никогда не покидает сервер: браузер обращается к собственному эндпоинту /api/chat, а функция подставляет ключ из окружения. Переменные с префиксом VITE_ для секретов запрещены — Vite встраивает их в бандл. Детали — в SECURITY.md.
- Ограничение злоупотреблений: проверка Origin, лимит размера тела и истории диалога, скользящее окно частоты запросов, таймаут обращения к провайдеру.
- Динамический UI: сайдбар полностью сворачиваемый. Для предотвращения бага «серой зоны» на карте (когда Leaflet не успевает за анимацией) используется ResizeObserver в компоненте InvalidateMapSize.
- Визуализация пути: точки маршрута на карте помечаются кастомными маркерами с порядковыми номерами (1, 2, 3...), которые обновляются при перетаскивании (drag-and-drop) элементов в списке.
- Темизация: реализована глубокая темная тема, включая кастомную стилизацию карты через CSS-фильтры (invert, hue-rotate) для сохранения читаемости дорог.

## 5. Последние важные изменения (History)

- Оптимизация: полностью удален функционал OCR (распознавание фото), так как он был нестабилен и перегружал интерфейс.
- Исправление AI: промпт AI переведен из режима «медицинского советника» в режим «навигатора-поисковика», чтобы избежать блокировок безопасности (Safety Filters) со стороны Google Gemini.
- UI/UX: исправлены рывки анимации сайдбара, удалены дублирующие кнопки сброса, добавлена плавная подстройка размера карты под ширину экрана.
- Безопасность: ключ LLM вынесен из клиентского бандла в serverless-функцию, добавлены CSP и остальные защитные заголовки (vercel.json), нормализация ответа модели, ограничение частоты запросов.
- Устойчивость: добавлен ErrorBoundary вместо белого экрана, валидация данных из localStorage, защита от отсутствующих полей в источниках данных.
- Производительность: дебаунс поиска, единый индекс подсказок, Set для избранного, ленивая загрузка AI-помощника и разделение бандла на чанки.
- Доступность: язык страницы ru, разрешено масштабирование на мобильных, aria-метки для кнопок, видимый фокус, поддержка prefers-reduced-motion, window.alert заменён неблокирующими уведомлениями.

## 6. Структура данных

- src/doctors.js: основная база данных врачей.
- src/kazanFacilities.js: база медицинских учреждений (OpenStreetMap, ODbL).
- src/ClinicsData.js: верифицированные клиники с расписаниями.
- src/App.jsx: главный компонент, управляющий состоянием карты, фильтров и маршрутов.
- src/AIAssistant.jsx: интерфейс чата с AI.
- src/services/ai.js: клиент собственного эндпоинта /api/chat.
- api/chat.js: серверный прокси к провайдеру LLM.
- api/_shared/: промпт, нормализация ответа, ограничение частоты запросов.
