# MedКарта — Интеллектуальная Навигация по Медицине Казани

![MedKarta](https://img.shields.io/badge/MedKarta-1.0-blue?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=for-the-badge)

**MedКарта** — веб-приложение для поиска врачей и медицинских учреждений
в Казани: карта, фильтры, расписания, построение маршрутов и AI-навигатор.

## 🚀 Возможности

- **Интерактивная карта** — сотни клиник и врачей с кластеризацией маркеров.
- **AI-навигатор** — подбор специалиста по описанию и построение маршрута
  через чат; запросы идут через собственный серверный эндпоинт.
- **Умная маршрутизация** — до 5 точек в маршруте, режимы «авто / пешком / велосипед».
- **Глубокая фильтрация** — районы, специальности, рейтинг, стаж, услуги,
  доступная среда, детский приём, вечерние и выходные часы.
- **Тёмная тема** — включая стилизацию карты.
- **Мобильная адаптивность** — нижняя панель, bottom sheet, safe-area.

## 🛠 Технологии

- React 19 + Vite
- Tailwind CSS 4
- Leaflet / React-Leaflet / leaflet-routing-machine
- Vercel Functions (серверный прокси к LLM)
- Lucide React (иконки)

## ⚙️ Запуск

```bash
npm ci
cp .env.example .env      # и вписать OPENROUTER_API_KEY
npm run dev               # http://127.0.0.1:5173
```

`npm run dev` поднимает и фронтенд, и обработчик `/api/chat` — ключ остаётся
на стороне dev-сервера и в бандл не попадает.

Проверка и сборка:

```bash
npm run lint
npm run build
npm run preview
```

## 🔐 Ключи и переменные окружения

Секреты **не должны** иметь префикс `VITE_`: Vite подставляет такие переменные
прямо в JS-бандл, и они становятся видны любому посетителю сайта.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `OPENROUTER_API_KEY` | да | ключ провайдера LLM, читает только `backend/api/chat.js` |
| `AI_UPSTREAM_URL` | нет | переопределение адреса провайдера |
| `AI_MODEL` | нет | переопределение модели |
| `ALLOWED_ORIGINS` | нет | доверенные Origin, если фронт на другом домене |

В Vercel те же переменные задаются в **Settings → Environment Variables**.

Подробности модели угроз и принятых мер — в [SECURITY.md](./SECURITY.md).

## 🗂 Структура

```
api/
  chat.js              серверный прокси к LLM (Vercel Function)
  _shared/
    prompt.js          системный промпт — только на сервере
    sanitize.js        белые списки и лимиты для ответа модели
    rateLimit.js       ограничение частоты запросов
src/
  App.jsx              карта, фильтры, маршруты
  AIAssistant.jsx      окно чата
  ErrorBoundary.jsx    экран вместо белой страницы при сбое
  Toast.jsx            неблокирующие уведомления
  hooks/               localStorage с валидацией, дебаунс
  services/ai.js       клиент /api/chat
  doctors.js           справочник врачей
  kazanFacilities.js   выгрузка учреждений (OpenStreetMap, ODbL)
  ClinicsData.js       верифицированные клиники
```

## 📊 Источники данных

Данные учреждений частично получены из OpenStreetMap и распространяются
на условиях ODbL. Маршруты строятся публичным сервисом
`routing.openstreetmap.de`, тайлы карты — `tile.openstreetmap.org`.

## ⚠️ Оговорка

Приложение помогает найти учреждение и специалиста. Оно не ставит диагнозы
и не заменяет консультацию врача. При неотложном состоянии звоните 103 или 112.
