# Глоссарий

Термины используются во всей документации в одном значении.

| Термин | Значение |
|---|---|
| **Privacy Gateway** | модуль [gateway.js](../backend/privacy/gateway.js): разбирает реплики пользователя в доверенном контуре и решает, что может уйти внешней модели |
| **Доверенный контур** | сервер МедКарты и его хранилища; за его границей — провайдер модели, тайлы карты, внешние карты |
| **`SanitizedPlannerRequest`** | единственный тип, который принимает внешний планировщик; создаётся только в Privacy Gateway ([models.js](../backend/privacy/models.js)) |
| **Метка (токен)** | непрозрачная замена сущности: `@DOCTOR_A`, `@CLINIC_B`, `@PERSON_A`, `@PHONE_A`; места — `@HOME`, `@CURRENT_LOCATION`, `@WORK` |
| **Token Vault** | хранилище соответствий «метка → сущность» с ключом от сессии и запроса и TTL ([tokenVault.js](../backend/storage/tokenVault.js)) |
| **Псевдонимизация** | замена данных метками с возможностью обратного сопоставления; в проекте — не обезличивание |
| **Режим `structured`** | режим по умолчанию: модель получает только описание из перечислимых значений, без слов пользователя |
| **Режим `hybrid`** | слова пользователя уходят модели, если все они из закрытого словаря, иначе — описание |
| **Закрытый словарь** | список допустимых слов исходящего текста ([vocabulary.js](../backend/privacy/vocabulary.js)) |
| **Fail-closed** | при сомнении данные наружу не отправляются; ответ строится локально |
| **Планировщик** | компонент, превращающий запрос в JSON-план из перечислений: внешний (модель) или локальный (правила) |
| **План** | `{action, steps, constraints, reply_hint, travel_mode, sort_mode, services}` ([schema.js](../backend/planner/schema.js)) |
| **Validator** | строгая проверка плана модели ([validator.js](../backend/planner/validator.js)) |
| **Policy Engine** | авторизация плана в сессии: токены, бюджет сложности ([policyEngine.js](../backend/executor/policyEngine.js)) |
| **Executor** | исполнение плана по справочнику ([actions.js](../backend/executor/actions.js)) |
| **Result Builder** | сборка ответа интерфейсу по шаблонам ([resultBuilder.js](../backend/executor/resultBuilder.js)) |
| **Действие интерфейса** | нормализованный ответ `/api/chat` — фильтры, маршрут, текст ([shared/contract.js](../shared/contract.js), `sanitizeAiAction`) |
| **Красный флаг** | признак неотложного состояния; ответ — «звоните 103 или 112» |
| **Справочник** | данные о врачах, клиниках и учреждениях, с которыми работает ассистент ([catalog.js](../backend/privacy/catalog.js)) |
| **Профиль (специальность)** | один из 16 ключей `SPECIALTY_CANON` ([shared/specialties.js](../shared/specialties.js)) |
| **Демо-режим** | `DEMO_DATA=on`: вымышленные врачи, цены, расписание, программы ДМС, демо-запись и демо-аккаунты |
| **Реальная клиника демо-набора** | частная клиника Казани с настоящими названием, адресом, точкой и часами (OSM) и вымышленными врачами |
| **Строгий подбор** | подбор свободного времени, в котором каждое условие обязательно ([search.js](../backend/demo/search.js)) |
| **Условия записи** | день, часы, цена, ДМС, район, пол и стаж врача и др., извлечённые из текста детерминированно |
| **Воронка (`funnel`)** | число кандидатов после каждого условия подбора |
| **Послабление (`relax`)** | предложение снять условие с числом вариантов; применяется только с согласия пользователя |
| **Слот** | интервал приёма врача в филиале; статусы `FREE`, `HELD`, `BOOKED`, `BLOCKED` |
| **Удержание (hold)** | временная бронь слота на 5 минут на время подтверждения |
| **Ключ идемпотентности** | `idempotencyKey`: повтор запроса записи возвращает ту же запись |
| **Граф дорог** | файл `data/graph/kazan.graph` формата `GMK1` |
| **Привязка (snap)** | проекция точки на ближайший подходящий отрезок дороги |
| **Главная компонента** | самая большая сильно связная компонента графа для профиля передвижения |
| **Профиль передвижения** | `driving`, `foot`, `bike` |
| **Один ко многим** | один обход Дейкстры от точки до многих целей с потолком времени |
| **Ведро процессорного времени** | лимит на адрес по затраченным миллисекундам с линейным пополнением ([rateLimit.js](../backend/http/rateLimit.js)) |
| **Предохранитель нагрузки** | общий для процесса лимит доли тяжёлой работы за 10 секунд |
| **Программа ДМС** | набор правил покрытия «филиал × специальность или услуга → режим доступа» ([shared/dms.js](../shared/dms.js)) |
