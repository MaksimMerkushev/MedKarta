# 18. Известные ограничения и риски

Документ собирает в одном месте то, что продукт **не умеет**, какие
архитектурные риски у текущего решения, какие проблемы найдены при аудите
документации (код при этом **не исправлялся**) и что проверить не удалось.

## Ограничения продукта

| Область | Ограничение | Подробно |
|---|---|---|
| Ассистент | Разбор текста — правила и словари, а не модель: необычная формулировка может быть понята не полностью. Понятые условия показываются, непонятое не додумывается | [06-ai-assistant.md](06-ai-assistant.md) |
| Ассистент | Сервер не хранит диалог: контекст — последние 20 реплик пользователя, которые присылает браузер; перезагрузка вкладки его теряет | [06-ai-assistant.md](06-ai-assistant.md) |
| Ассистент | Качество плана настоящей модели не покрыто автоматическими тестами | [16-testing.md](16-testing.md) |
| Медицина | Классификатор жалоб — правила; диагнозов нет; при неуверенности — уточняющий вопрос | [10-medical-search-and-data.md](10-medical-search-and-data.md) |
| Данные | Публичный срез врачей — 6 записей; полная база вне git; рейтингов, стажа и слотов в открытых данных нет | [10-medical-search-and-data.md](10-medical-search-and-data.md) |

| Запись | Записи в реальные клиники нет; демо-запись — симуляция на вымышленных данных | [11-demo-booking.md](11-demo-booking.md) |

## Архитектурные риски

| # | Риск | Последствие | Где |
|---|---|---|---|
| R1 | Лимиты частоты, бюджеты CPU, предохранитель, Token Vault (по умолчанию) и кеши живут **в памяти одного процесса** | при нескольких экземплярах лимиты складываются, метки одного экземпляра не разыменовываются другим; рестарт обнуляет состояние | [rateLimit.js](../backend/http/rateLimit.js), [tokenVault.js](../backend/storage/tokenVault.js) |
| R2 | Разбор реплик и поиск маршрутов идут в **основном потоке** одного процесса | тяжёлые запросы задерживают остальные; смягчено очередью и бюджетами, но не устранено | [05-backend.md](05-backend.md) |
| R3 | **Метрики не экспортируются** | нет наблюдаемости по решениям Gateway, отказам планировщика и задержкам, кроме журнала | [metrics.js](../backend/observability/metrics.js) |
| R4 | Нет эндпоинта проверки здоровья и CI-конфигурации в репозитории (каталога `.github/` нет) | тесты и линтер запускаются вручную; мониторинг доступности — только внешний | — |
| R5 | `App.jsx` — 4 630 строк, нет тестов компонентов интерфейса | изменения интерфейса трудно проверять; регрессии ловятся вручную | [App.jsx](../frontend/src/App.jsx) |
| R6 | Полная база врачей подставляется в браузерный бандл | все записи скачиваются любым посетителем | [vite.config.js](../vite.config.js) |
| R7 | Адрес модели по умолчанию — `modelhub.my` | ключ другого провайдера уйдёт туда, если `AI_UPSTREAM_URL` не задан (есть предупреждение в журнале) | [pipeline.js](../backend/pipeline.js) |
| R8 | Тайлы карты — `tile.openstreetmap.org` | правила OSM для коммерческой нагрузки, раскрытие в политике конфиденциальности | [deployment.md](deployment.md) |
| R9 | Факт обращения (профиль и условия) уходит провайдеру модели | сведения о здоровье без слов пользователя; снимается только локальной моделью | [07-privacy.md](07-privacy.md) |
| R10 | Псевдонимизация обратима | Token Vault — чувствительный актив | [07-privacy.md](07-privacy.md) |
| R11 | Проверка сборщика на внутренние адреса — по имени хоста, без проверки адреса после DNS | имя, указывающее на внутреннюю сеть, пройдёт проверку | [fetchSource.js](../tools/data/fetchSource.js) |
| R12 | Правовые вопросы (152-ФЗ, трансграничная передача, данные врачей, дети) | техническими мерами не решаются | [privacy-architecture.md](privacy-architecture.md), раздел 10 |

## Найденные проблемы

изменялся** — по условию задачи проблемы в коде только фиксируются.
Неточности в документах исправлены в рамках этой работы; это отмечено в
колонке «Статус».
