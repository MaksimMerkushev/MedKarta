# Устаревшая конфигурация

Здесь лежит то, что больше не применяется, но выбрасывать рано.

## `vercel.json`

Проект больше не разворачивается на Vercel. Файл сохранён как справка
и **не действует**.

**Важно, что из него ушло.** Весь набор заголовков безопасности — CSP,
HSTS, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` — жил
только здесь. После переезда на собственный сервер он перестал
применяться совсем: `backend/server.js` не выставлял ни одного заголовка,
и заметить это по коду было невозможно.

Теперь заголовки определены в `backend/http/securityHeaders.js`,
выставляются на каждый ответ и закреплены тестом в
`tests/boundary.test.js`. Конфигурация платформы для этого больше не нужна,
и при следующем переезде набор не потеряется.

Если статику отдаёт nginx, а не `backend/server.js`, заголовки для HTML
обязан выставлять nginx — см. `docs/deployment.md`.
