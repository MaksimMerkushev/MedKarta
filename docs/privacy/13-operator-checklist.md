# 13. Чек-лист оператора

Что сделать до открытия регистрации в production. Код уже не даёт открыть
регистрацию, пока в политике и соглашении есть метки
`[ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ]` (проверка — `npm run accounts -- legal-status`).

## Реквизиты и документы

- [ ] Наименование (ФИО), правовой статус, ИНН/ОГРН (ОГРНИП), адрес оператора
- [ ] Ответственный за организацию обработки ПДн, email и почтовый адрес для обращений
- [ ] Юридическая проверка политики, соглашения и ответов на [вопросы](12-legal-questions.md)
- [ ] Новая редакция документов без меток: новый файл `legal/<документ>/<дата>.md`,
      `node scripts/legal-manifest.mjs --current <документ> <дата>`; прежние файлы не менять
- [ ] Локальные акты: положение об обработке ПДн, порядок доступа, порядок уничтожения
      (с формой акта), порядок реагирования на инциденты; ознакомление сотрудников
- [ ] Договоры-поручения с хостингом и почтовым сервисом (ч. 3 ст. 6)

## Инфраструктура

- [ ] Подтвердить местоположение VPS и резервных копий в РФ (адрес ЦОД, провайдер)
- [ ] Выбрать почтовый сервис (серверы в РФ или уведомление о трансграничной передаче)
- [ ] Решить по модели: поставщик и страна серверов `AI_UPSTREAM_URL` / уведомление по ст. 12 /
      работа без внешней модели (не задавать ключ)
- [ ] Если задан `AI_PROXY_URL` — кто провайдер прокси и где он
- [ ] Не использовать `TOKEN_VAULT_BACKEND=upstash` с `*.upstash.io` (код и так отключит, но в журнале будет ошибка)
- [ ] Cloudflare: подтвердить режим «DNS only» для сайта
- [ ] nginx: срок ротации журнала (например, 14 дней) — и вписать его в политику (п. 4.10)
- [ ] Резервные копии: `backup --encrypt`, ключ `BACKUP_ENCRYPTION_KEY` — отдельно от копий и
      от `.env`; срок хранения копий; процедура восстановления с `reapply-erasures`
- [ ] Ежедневно сохранять вне сервера вывод `npm run accounts -- consents-verify`

## Регулятор

- [ ] Определить уровень защищённости ИСПДн (ПП РФ № 1119) и меры ([09](09-security-measures.md))
- [ ] Уведомление по ст. 22 ([11](11-rkn-notification.md)); при трансграничной передаче — по ч. 3 ст. 12 до её начала
- [ ] Порядок уведомления об инцидентах в 24/72 часа и контакт для Роскомнадзора ([07](07-incident-response.md))

## Процессы

- [ ] Назначить сотрудников с правом `privacy.requests`; проверять «Обращения по ПДн»
      не реже раза в рабочий день (`npm run accounts -- privacy-requests`)
- [ ] Порядок ответа на обращения по почте и проверки личности ([06](06-subject-requests.md))
- [ ] Пересмотреть срок `user_activity` (400 дней) и журнала действий (365 дней)
- [ ] Процедура для врачей из справочника: уточнение и удаление сведений

## После всех пунктов

- [ ] Открыть регистрацию (`REGISTRATION_MODE=open`); убедиться, что `LEGAL_DRAFTS_ALLOWED` не задан
- [ ] Проверить `/legal/privacy`, `/legal/terms`, форму регистрации, «Мои данные»
