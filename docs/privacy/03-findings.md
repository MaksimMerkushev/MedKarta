# 03. Найденные нарушения и риски

Аудит кода ветки `feature/secure-auth` до изменений 26.10.2026 (коммит
`6ffaf26`). «Исправлено» — изменение в коде с тестом; «осталось» — нужно
решение оператора, юриста или настройка сервера.

## Осталось

| № | Что | Риск | Кто решает | Что нужно |
|---|---|---|---|---|
| R1 | Реквизиты оператора, ответственный, адреса для обращений | документы недействительны; регистрация закрыта | оператор | [13-operator-checklist.md](13-operator-checklist.md) |
| R2 | Местоположение VPS и резервных копий не подтверждено | ч. 5 ст. 18 — локализация баз | оператор | договор хостинга, адрес ЦОД |
| R3 | Почтовый сервис не выбран / не подтверждён | email уходит третьему лицу; возможна трансграничная передача | оператор | договор (поручение, ч. 3 ст. 6), страна серверов |
| R4 | Поставщик языковой модели: по умолчанию `modelhub.my`, по документации возможен OpenRouter (США), есть `AI_PROXY_URL` | трансграничная передача (ст. 12) — даже для описаний без слов пользователя, если юрист сочтёт их ПДн | оператор, юрист | либо модель в РФ, либо уведомление о трансграничной передаче, либо отключить внешнюю модель (`AI_API_KEY` не задавать — ассистент работает на локальном планировщике) |
| R5 | Тайлы OpenStreetMap грузятся напрямую из браузера | IP посетителя получает OSMF (Великобритания) и CDN | юрист | квалификация; альтернатива — собственный сервер тайлов в РФ |
| R6 | Журнал nginx пишет полный IP; срок ротации не задан в репозитории | хранение дольше цели | оператор | срок в logrotate (например, 14 дней) и в политике п. 4.10 |
| R7 | `.env` по инструкции копируется вместе с базой | ключ MFA и ключ писем рядом с данными — копия перестаёт быть защищённой | оператор | хранить `.env` и копии базы раздельно; использовать `--encrypt` с отдельным ключом ([05](05-retention-and-destruction.md)) |
| R8 | Справочник врачей: ФИО, стаж, рейтинг из открытых источников | основание для публикации ПДн врачей не определено | юрист | [12-legal-questions.md](12-legal-questions.md) |
| R9 | `user_activity` (дни посещения по аккаунту) хранится 400 дней | цель — статистика DAU/MAU; срок и основание не обоснованы | оператор, юрист | сократить срок или хранить агрегаты без id |
| R10 | Уведомление Роскомнадзора по ст. 22 не подавалось | обработка без уведомления | оператор | [11-rkn-notification.md](11-rkn-notification.md) |
| R11 | Модель угроз и уровень защищённости ИСПДн (ПП РФ № 1119) не определены | ст. 19 | оператор | [09-security-measures.md](09-security-measures.md) |
| R12 | Отпечаток журнала согласий (anchor) не сохраняется вне сервера | тот, у кого есть доступ к файлу базы, может переписать цепочку целиком | оператор | раз в сутки сохранять вывод `npm run accounts -- consents-verify` вне сервера; сверка — `--as-of` |
| R13 | Классификатор жалоб — правила | жалоба, не узнанная словарём, может уйти описанием «врач, профиль не указан» (слов пользователя в нём нет) | разработка | пополнять словарь по `npm run eval:privacy` |

| R15 | Акт об уничтожении по требованиям Роскомнадзора | ч. 7 ст. 21, приказ РКН от 28.10.2022 № 179 | оператор | форма акта и выгрузка из журнала ([05](05-retention-and-destruction.md)) |
