## Исходные данные для определения уровня защищённости

Для решения оператора (ПП РФ № 1119), без вывода о самом уровне:

- категории: обычные ПДн (аккаунты, сотрудники); специальные категории
  (сведения о здоровье) **по построению не хранятся и не связываются с
  субъектом** — если юрист квалифицирует иначе ([12](12-legal-questions.md),
  вопросы 1–3), категория меняется;
- субъекты: не являющиеся сотрудниками оператора (пользователи) и
  сотрудники;
- число субъектов: [ТРЕБУЕТСЯ ЗАПОЛНИТЬ] (`npm run accounts -- status`);
- тип актуальных угроз: определяется моделью угроз оператора (наличие
  недекларированных возможностей в системном и прикладном ПО); исходные
  материалы — [auth-threat-model.md](../auth-threat-model.md),
  [privacy-architecture.md](../privacy-architecture.md).

Состав и содержание мер для выбранного уровня — приказ ФСТЭК России от
18.02.2013 № 21; сверить с действующей редакцией юристу или специалисту по
защите информации.
