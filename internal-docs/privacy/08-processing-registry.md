# 08. Внутренний реестр процессов обработки

Перечень процессов обработки для внутреннего учёта оператора (ст. 18.1:
документы, определяющие политику и процедуры). Машиночитаемая часть — в
`backend/legal/processing.js` (`PROCESSING_REGISTRY`, версия `2026-10-26`):
она же попадает в выгрузку «Мои данные» и в ответ `GET /api/privacy`. При
изменении процесса меняются оба места, политика (`legal/privacy-policy/`) и,
если нужно, уведомление в Роскомнадзор (ч. 7 ст. 22).

Общие сведения для всех процессов:

- Оператор: [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ]
- Ответственный за организацию обработки: [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ]
- Информационная система: МедКарта (navimed.tech), сервер — [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ: провайдер, адрес ЦОД]
- Способ обработки: автоматизированный
- Действия: сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, блокирование, удаление, уничтожение; передача — только там, где указано

этом документе: пользователю в выгрузке они не показываются, потому что
либо не касаются его аккаунта, либо описаны в политике (п. 4.9, 4.10, 8).
