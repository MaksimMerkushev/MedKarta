# 11. Уведомление Роскомнадзора об обработке (ст. 22)

Уведомление подаёт оператор **до начала** обработки (ч. 1 ст. 22); исключения
ч. 2 ст. 22 узкие, и на сервис с публичной регистрацией пользователей они,
по оценке технической команды, не распространяются — подтвердить юристу.
Подаётся через портал персональных данных Роскомнадзора, подписывается
уполномоченным лицом оператора. Этот документ — чек-лист сведений; сам
документ не подан, и нигде в проекте нельзя утверждать, что оператор внесён
в реестр операторов, пока это не подтверждено выпиской.

Изменения сведений сообщаются не позднее 15-го числа месяца, следующего за
месяцем изменения (ч. 7 ст. 22) — сверить срок с действующей редакцией.

## Сведения (по ч. 3 ст. 22) и откуда их взять

| Сведение | Значение / источник |
|---|---|
| Наименование (ФИО), адрес оператора | [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ] |
| Цели обработки | [08-processing-registry.md](08-processing-registry.md): аккаунт, безопасность, служебные письма, ассистент, демо-запись, учёт документов, обращения, статистика, сотрудники, журналы, справочник врачей |
| Категории персональных данных | [01-data-map.md](01-data-map.md); специальные категории — **не обрабатываются** при текущем построении ([04](04-health-data.md)) — если юрист решит иначе, указать |
| Категории субъектов | пользователи сервиса; работники и привлечённые лица оператора; врачи из справочника; посетители сайта (журналы) |
| Правовые основания | [02-legal-bases.md](02-legal-bases.md) |
| Перечень действий и способы обработки | сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, блокирование, удаление, уничтожение; передача — почтовому сервису [и поставщику модели — по решению]; автоматизированная обработка |
| Меры по ст. 18.1 и 19, включая сведения о средствах защиты и шифрования | [09-security-measures.md](09-security-measures.md) — после определения уровня защищённости |
| ФИО ответственного за организацию обработки, телефон, почтовый адрес, email | [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ] |
| Дата начала обработки | [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ] |
| Срок или условие прекращения обработки | [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ] (например, ликвидация оператора / прекращение работы сервиса) |
| Наличие трансграничной передачи | [10-processors-and-localization.md](10-processors-and-localization.md) — заполнить после выбора почтового сервиса и модели; если передача есть — отдельное уведомление по ч. 3 ст. 12 **до** её начала |
| Место нахождения баз данных (страна, адрес ЦОД) | [ТРЕБУЕТСЯ ЗАПОЛНИТЬ ОПЕРАТОРОМ] |
| Сведения об обеспечении безопасности в соответствии с требованиями Правительства РФ | уровень защищённости по ПП № 1119 — [ТРЕБУЕТСЯ ЗАПОЛНИТЬ] |

## Порядок

1. Заполнить реквизиты и ответственного ([13](13-operator-checklist.md)).
2. Определить почтовый сервис, хостинг, поставщика модели; при трансграничной
   передаче — уведомление по ст. 12 до её начала.
3. Определить уровень защищённости и меры.
4. Подать уведомление; сохранить подтверждение и номер в реестре.
5. Только после этого — убрать метки из документов, опубликовать новую
   редакцию (`scripts/legal-manifest.mjs`) и открыть регистрацию.

Автоматически ничего не подаётся и подаваться не должно.
